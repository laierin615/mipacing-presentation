# 耆老好會 · Pacing 海味藏冰箱 — 雙模式網頁簡報

> 解密阿美族 Mipacing 漁獵文化的科學智慧
> 臺東縣 Salimpo 阿美山海文化實驗小學 · 114 學年度科學展覽

## 🎯 對應科展審查標準

本網頁針對科展五大評分標準設計：

| 評分項目 | 比重 | 對應網頁區塊 |
|---------|------|--------------|
| 作品構想說明 | 5% | 第 1 章「為什麼研究 Mipacing」 |
| 研究方法與步驟 | **30%** | 各實驗章節「研究假設 / 實驗變因 / 實驗步驟」結構化區塊 |
| 原住民族知識內涵 | 20% | 阿美語辭典、5 位耆老介紹、田野訪談、文化禁忌 |
| 科學知識內涵 | 20% | 各實驗章「📚 深入學術原理」展開區（公式、推導、誤差分析、引用） |
| 科學知識與原民知識的對話 | 25% | 第 10 章「耆老的話 = 科學的話 = 我們的對話」 |

**視訊簡報 10 分鐘**：側邊欄章節有 ⭐ 標記者，為 10 分鐘簡報精選（共 10 章）
**視訊問答 10 分鐘**：第 13 章「Q&A 準備區」內含 15 張題目卡，學生可練習作答

---

## 🚀 怎麼開？

**最簡單的方法**：直接在 Finder 雙擊 `index.html`，會用預設瀏覽器（Safari / Chrome）打開。

> ⚠️ 不需要架設伺服器、不需要安裝任何東西。整個資料夾複製到 USB 或別台電腦也能用。

---

## 🎤 簡報模式（給研究團隊發表用）

按右上角「🎤 簡報」切換到簡報模式。

| 操作 | 鍵盤快速鍵 |
|------|-----------|
| 下一張 | `→` 或 `空白鍵` 或 `PageDown` |
| 上一張 | `←` 或 `PageUp` |
| 全螢幕 | `F` 或點右上角 ⛶ |
| 切換模式 | `M` |

**發表會建議**：
1. 開啟 `index.html` 後按 `F` 進入全螢幕
2. 按 `→` 從第 0 章封面開始
3. 第 4–8 章每張投影片都搭配耆老引言＋實驗數據＋結論
4. 第 13 章致謝後可按 `M` 切到自學模式給評審現場玩互動

## 🧒 自學模式（給中年級學生 + 老師深度自學）

預設就是自學模式。學生可以：

- **左側點章節** 跳到想看的部分
- **點擊阿美族語**（虛線標示）跳出解釋彈窗 + 🔊 念給你聽
- **5 個動手玩**：
  - 第 4 章：拖月亮看潮汐
  - 第 5 章：浮沉子配重模擬器
  - 第 6 章：折射滑桿（拉水深看魚位置偏差）
  - 第 7 章：CO₂ 累積計時器（按住模擬閉氣）
  - 第 8 章：海底地圖配對（拖魚到正確棲地）
- **第 12 章小測驗**：10 題答對 8 題以上得「🏆 小耆老獎章」
- **第 13 章 Q&A 準備區**：15 張題目卡分 4 類（科學原理、研究方法、原民知識、應用意義），點擊展開看建議回答方向

### 📚 深入學術原理（給老師 + 想深學的同學）

實驗 1-4 章節下方都有「📚 深入學術原理」深藍色展開區，點開後可看到：
- **核心公式**（含解釋）：阿基米德原理、斯涅爾定律、肺泡氣體交換等
- **推導與應用**（5 個要點）
- **誤差來源**（5 個層面，幫助學生回答評審追問）
- **進階討論**（連結現代科學前沿，如 Argo 浮標、射水魚演化、太空醫學）
- **學術引用**（每個實驗 4-5 篇真實學術文獻）

## ✏️ 怎麼修改內容？

所有文字內容集中在 `data/chapters.js`，用 VS Code 或記事本打開：

- 第 X 章的標題、文字、圖片路徑都在 `CHAPTERS` 陣列中
- 阿美語詞彙在 `AMIS_GLOSSARY`
- 耆老介紹在 `ELDERS`

改完存檔，重新整理網頁就會看到變更。

## 🔊 朗讀功能說明

| 內容 | 朗讀方式 |
|------|---------|
| 中文敘事文（🔊 按鈕） | 瀏覽器內建的 Web Speech API（中文女聲） |

**注意**：阿美語音檔目前是用 macOS 內建語音合成，發音不完全標準。建議搭配老師現場示範或部落耆老錄音再錄一遍替換 `assets/audio/narration/amis_*.m4a`（同檔名取代即可）。

## 🌐 離線使用

完全離線可用！只要把整個 `mipacing-presentation/` 資料夾複製過去，雙擊 `index.html` 就能開。

**唯一需要網路的地方**：Tailwind CSS 與 Chart.js 從 CDN 載入。如果發表現場完全沒網路：
- 簡報基本內容仍可正常顯示（樣式會稍微簡陋）
- 圖表（chart）將無法顯示
- 解決方案：發表前先在有網路時打開一次，瀏覽器會 cache CDN 資源

## 🎓 給老師的教學建議

**課前準備（建議用一節課做）**：
1. 學生先看完第 0–3 章（封面 + 動機 + 方法）
2. 老師講解什麼是「假設」「變因」（第 2 章）

**主要學習（5 節課，每節聚焦一個實驗）**：
- 第 1 節：實驗 1 月相 × 潮汐 → 玩拖月亮互動
- 第 2 節：實驗 2 浮力 → 玩浮沉子配重
- 第 3 節：實驗 3 折射 → 玩折射滑桿
- 第 4 節：實驗 4 生理學 → 玩 CO₂ 計時器（注意：學生可能會比賽憋氣，要事先約定「這是模擬，不要比賽」）
- 第 5 節：實驗 5 永續 → 玩海底地圖配對

**收束（建議用一節課做）**：
- 完成第 12 章小測驗
- 印出獎章作為學習成果
- 第 13 章致謝可作為參觀阿美族部落的引子

## 📝 已知限制

- **阿美語音檔**：用 macOS 英文語音合成，非標準發音（標示為 ⚠️ 待替換為部落耆老實錄）
- **照片授權**：僅供校內 + 科展現場使用，不可上網公開分享
- **互動模擬器**：在較舊瀏覽器（IE、舊版 Safari）可能無法正常運作，建議使用 Chrome / Edge / Safari 16+

---

## 🛠️ 技術細節

- **無打包工具**：純 HTML + Vanilla JS + Tailwind CDN
- **資料分離**：13 章節資料寫在 `data/chapters.js`，老師可獨立編輯
- **路由**：hash-based（`#/ch/05` 直達第 5 章，可分享連結）
- **音訊**：m4a (AAC) 格式，所有現代瀏覽器支援
